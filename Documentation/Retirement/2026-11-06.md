# GifForge retirement — November 6, 2026

GifForge was retired at the owner's request. The owner confirmed personal testing only and selected GitHub as the sole source archive, with local checkout deletion after archive verification. This document records observed outcomes rather than treating a successful delete request as proof of completion.

- Removed all inventoried repository deployment secrets and variables from `nonprod` and `prod`. The `shared` environment and repository-level settings contained no secrets or variables. No deployment keys or webhooks were present.
- Deleted `GifForge-GitHub-Actions-nonprod` and `GifForge-GitHub-Actions-prod` application registrations/service principals and their inventoried role assignments.
- Deleted all three resource groups: `rg-gifforge-prod`, `rg-gifforge-nonprod`, and `rg-gifforge-shared`. Final live queries returned no matching resource groups or resources, including the former Gifster name.

Ownership was established through tags, resource references, and 90-day application-log sources; PumpSync uses a different workspace.

The final deleted-workspace query returned no GifForge workspaces.

## Retained data and restrictions

- Azure SQL Ledger retains dropped tables, history, and ledger views by design. The `gifforge` schema therefore remains with ledger artifacts. This is not a full physical erasure of test account/auth/usage history. Deleting or rebuilding the shared database was outside scope and was not performed.
- Apple refused removal of the main App ID `QS3GC3CT43.dev.ericslutz.gifforge`, reporting that it remains in use by the App Store. The App Store Connect record is removed, not erased from Apple's historical records.
- GitHub packages have a platform recovery window; deletion does not promise immediate physical destruction of every retained copy.
